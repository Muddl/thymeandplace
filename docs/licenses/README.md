# License evidence

Evidence for the rows in `docs/reference-data-licenses.md`, one directory per licensor or dataset (for example `meow/`, `geonames/`, `terraclimate/`, `natural-earth/`). Keep a dated snapshot of the terms page (PDF or saved HTML) or the licensor's written reply, with personal contact details removed, and name the file after the date it was captured, e.g. `2026-10-01-terms.pdf`.

`meow/` is empty on purpose: the Marine Ecoregions of the World terms haven't been confirmed yet, and the ocean dataset can't be approved until they are.
